## 2. Derivation changes (the recipe-following that gives crafted items their aspects)

- **Follow stonecutter recipes** like crafting ones. 1.14+ makes many block variants only on the stonecutter
  (polished blackstone family, chiseled quartz/tuff, deepslate brick/tile slabs, quartz slab/stairs...).
- **Follow smithing upgrades** (base item + addition, template not counted). Netherite gear is made only this way, so
  today it has *only* the generic tool/armour bonus - no Metallum, no Ignis.
- **Skip re-dye recipes when picking the cheapest recipe** (dye + any carpet/bed/wool). 1.21 added "recolour"
  recipes, and because they're the cheapest they win: carpets and beds currently come out as just the dye's value.

## 3. Crafted/manufactured items that deserve something extra

- **Trident**: has nothing at all (no recipe, and the port's weapon bonus only knows swords/bows) -> Aqua 10, Aversio 15, Motus 5.
- **Mace**: derived from its heavy core + breeze rod, but no weapon bonus -> add Aversio 12.
- **Crossbow**: gets no bow bonus -> add Aversio 10, Volatus 5 (what a bow gets).
- **Vanilla candles**: only honeycomb + string -> add Lux 5 (as Thaumcraft's own candles have).
- **Soul torch / soul lantern / soul campfire**: the soul soil's share rounds away -> add Spiritus 2.
- **Respawn anchor**: glowstone + crying obsidian only -> add Victus 5, Spiritus 5.
- **Lodestone**: add Motus 5 (it pulls compasses).

## 4. The port's own earlier placeholders (items the original never had)

- **Raw iron/gold/copper**: currently the original's *dust* values (Metallum 15, Perditio 1...). In 1.17+ they are what
  an ore drops instead of the ore block, so proposed: the original's *ore* values - raw iron Terra 5, Metallum 15;
  raw gold Terra 5, Metallum 10, Desiderium 10; raw copper Terra 5, Metallum 10, Permutatio 5.
- **`c:raw_materials/*` tags** (modded tin, silver, lead, uranium...): currently mapped from the original's
  *native cluster* values (clusters are the doubled, purified form - too rich; lead also adds Ordo twice). Proposed:
  that metal's ore value, same rule as the vanilla raw metals.
- **Netherite scrap** (Metallum 15, Ignis 10): fine as is.
- **Amethyst shard** (Vitreus 10, Praecantatio 5): Praecantatio is a stretch - amethyst isn't magic in vanilla, its
  defining trait is the chime/resonance (sculk calibration). Proposed: Vitreus 10, Sensus 5. (The buds/cluster in
  section 1 would follow: swap their Praecantatio for Sensus.)
- **Dyed shulker boxes**: all 16 point at the purple one - 1.12's default colour - which 1.21 no longer makes (it has an
  undyed box), so all 16 are empty. Proposed: point them at the undyed Shulker Box (listed in section 1 as purple).

## Not proposed (left without aspects)

Spawn eggs (80), command blocks, structure blocks, jigsaw, barrier, light, debug stick, knowledge book, petrified oak
slab, reinforced deepslate, trial spawner, vault, budding amethyst - creative/technical only. Potions, tipped arrows
and enchanted books already get theirs at runtime from their contents.

## Decisions (2026-09-29, with the user)

- Stonecutter recipes: follow them. Smithing upgrades: follow them (template not counted). Recolour recipes: skip.
- Raw metals (vanilla + modded `c:raw_materials`): the metal part only, no Terra - raw iron Metallum 15; raw gold
  Metallum 10, Desiderium 10; raw copper Metallum 10, Permutatio 5; modded ones = their ingot value.
- Amethyst shard: Vitreus 10, Sensus 5 (buds/cluster: Sensus instead of Praecantatio).
- Trident: Aqua 10, Aversio 15, Motus 5. Mace +Aversio 12. Crossbow +Aversio 10, Volatus 5.
- Vanilla candles +Lux 5; soul torch/lantern/campfire +Spiritus 2; Respawn Anchor +Victus 5, Spiritus 5; Lodestone +Motus 5.
- Later: should vanilla candles be usable where Thaumcraft recipes want Thaumcraft candles (like vials/bottles)?
- Approved as proposed: water plants, berries/small plants, lush cave & mangrove, sniffer plants, Nether blocks
  (nylium, wart block, shroomlight, mushroom stem), corals, carved pumpkin.
- Nether plants, fleshier (crimson Bestia, warped Victus): Crimson Fungus Herba 3, Bestia 2, Ignis 1; Crimson Roots
  Herba 2, Bestia 1, Ignis 1; Weeping Vines Herba 2, Bestia 1, Ignis 1, Motus 1; Warped Fungus Herba 3, Victus 2,
  Sensus 1; Warped Roots Herba 2, Victus 1, Sensus 1; Twisting Vines Herba 2, Victus 1, Sensus 1, Motus 1; Nether
  Sprouts (warped-forest plant) Herba 1, Victus 1, Sensus 1.
- Approved as proposed: new stone (calcite, basalt, blackstone, gilded blackstone, soul soil), dripstone,
  suspicious gravel/sand, ancient debris, amethyst buds/cluster (Sensus version), copper ageing, anvils, cracked
  variants (+Perditio 1), dried kelp (+Ignis 1).
- Smooth stone/sandstone/red sandstone/quartz/basalt: source + ORDO 1 (not Ignis).
- Infested blocks: block + Bestia 3, Vinculum 1.
- Sculk: as proposed + Alienis 2 each (Sculk Vein Alienis 1).
- Honeycomb: Ordo 3, Bestia 2, Fabrico 2. Other bee/egg items as proposed.
- Piglin Head: zombie head + Ignis 5. Other creature drops and froglights as proposed.
- Trial keys: Metallum 5, Instrumentum 5 (Ominous: + Tenebrae 5). Breeze rod, heavy core, ominous bottle as proposed.
- Bell: Metallum 10, Sensus 10, Ordo 3. Disc fragment and new discs as proposed.
- Suspicious Stew: mushroom stew + Alkimia 3. Filled Map: empty map + Cognitio 3. Other loot as proposed.
- Mob buckets: water bucket + the creature's own value (cod/salmon/pufferfish/tropical fish use the fish item;
  axolotl and tadpole Bestia 5, Victus 5). Powder snow bucket as proposed.
